# First Sync

Alive is not the end of becoming. It is the end of Birth. The first Sync is the first time the living Citizen accepts a signed change from outside without being born again.

## What occurred

After Birth, an update package waited in the seed’s updates plane. Sync checked for a newer signed Manifest compatible with the living Citizen, downloaded into staging, verified Asset signatures, and applied Assets into the living store. The Manifest advanced. Identity stayed the same.

Observed first sync outcome in the birth lab:

- Sync button / engine states moved through checking and update-available into updating and **Updated**.  
- Citizen version moved from the birth seed baseline to **`1.0.1-seed`**.  
- Runtime version remained **`0.1.0`**.  
- Compatibility remained **`seed-2026.1`**.  
- Release stamped on the applied package was observed as **`2026-08-01T12:00:00Z`**.  
- Asset set still centered on the four seed Asset ids, with content addressed by hashes (documentation Asset version advanced in the update package).

Timeline gained a *Sync* / *First Sync* node. Journal recorded the first sync in prose. Terminal spoke in organism language: listening, receiving, verifying, becoming, remembering.

## Why it occurred

Birth delivers genesis. Life requires the ability to change what one carries without discarding who one is. Sync is that ability: Assets and Manifest evolve; genome does not.

## What changed

- Manifest release and asset version.  
- Citizen version string (`1.0.1-seed` after first update package).  
- Asset payloads/hashes as listed in the new Manifest.  
- Projection refresh from new Assets.  
- Evidence and Telemetry of every sync state.  
- Journal and Timeline chapters of Sync.

## What remained

- `citizen_id`  
- Birth timestamp and identity seal  
- Append-only Evidence history from Birth  
- Compatibility family `seed-2026.1` (for this observed update)  
- Runtime version `0.1.0` (Assets updated; Runtime binary not replaced)

## What evidence exists

- Evidence: `UPDATE_STATE_*`, update available/complete marks.  
- Journal epoch *Sync*.  
- Timeline node *Sync*.  
- Manifest history archive of the previous release under the living manifest plane.  
- Birth Packages exported after Sync include the post-sync Manifest.  
- Observatory Sync panel states: Current → Update Available → Updating → Updated.

First Sync is still one Citizen. It is not a second Birth.
