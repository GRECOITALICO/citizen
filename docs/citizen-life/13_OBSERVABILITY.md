# Observability

Observability is how the Citizen (and a human witness) sees that life is happening.

## What the Citizen observes of itself

- **Identity** — who it is, how old it is since Birth, which Runtime and Manifest versions it carries.  
- **Sync posture** — whether it is Current, whether an update waits, whether it is Updating, whether it is Updated.  
- **Life Journal** — biographical prose of epochs.  
- **Timeline** — irreversible nodes; each can open related Evidence.  
- **Terminal** — the birth and sync narration in organism language.  
- **Telemetry** — continuous machine-facing stream of events and host samples.  
- **Evidence** — forensic event envelopes.  
- **Projection** — materialized Assets.  
- **Lab report** — measured inventory of living planes and LLM-import scan.

## How it observes

- Local Observatory UI served from the seed Runtime.  
- Append-only files in the living home.  
- CLI: status, boot, update, export-birth, lab-report.  
- Export Birth Package for offline witness.

## What it registers

Birth stages, boots, sync states, durations, versions, asset load counts, errors and warnings when they occur, host resource samples in the lab telemetry phase, journal epochs, timeline nodes.

## What it does not register (observed seed scope)

- Contents of conversations with a language model (none are used in measured seed life).  
- Passwords or operator secrets beyond the publisher secret kept in the living runtime plane for verification (not shown in the Observatory panels).  
- Remote network update channels (updates were local directory packages).  
- Other Citizens’ lives.  
- Invented future product metrics.

## What jamás (never) means here

In the birth-lab phase, telemetry was intentionally **not** reduced. “Never registers X” in this document means “not part of observed Citizen Seed life,” not a promise about all future production policies. Production reduction would be a later, evidenced chapter — not assumed here.
