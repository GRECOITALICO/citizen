# First Evolution

Evolution, in this life record, means growth **after** the first Sync: another accepted change in the same continuous Identity, remembered as a later chapter — not a reset.

## What occurred

The seed laboratory observed **First Sync** against a single published update package (`1.0.1-seed`). A distinct *First Evolution* Timeline chapter is reserved for the next successful Sync after that first one — when a newer signed package exists and is applied while Identity remains.

At the time this chapter was written for permanent documentation:

- First Sync was **observed**.  
- A second package-driven Sync (First Evolution as a separate Timeline epoch) was **not yet observed** in the same living home, because only one update package was present in the seed updates directory.

The machinery already distinguishes the chapters: the Update Engine records epoch *Sync* for the first completed update on the Timeline, and epoch *Evolution* when a Sync node already exists and another update completes.

## Why this distinction matters

If every change were called “install,” life would look like replacement. Calling the second growth *Evolution* preserves the story: the same organism changed again, and both changes remain in Journal and Evidence.

## What would change in a First Evolution (when observed)

- A newer Manifest release and asset version.  
- New or replaced Asset hashes.  
- New Evidence, Telemetry, Journal prose, Timeline *Evolution* node.  
- Updated Projection.

## What would remain

- The same `citizen_id` and Birth genome.  
- All prior Evidence and Journal chapters.  
- The fact of First Sync in history.

## What evidence will count

When First Evolution is observed, this life record does not rewrite this page’s past sentences about “not yet observed.” A **new chapter** will be appended to [Longitudinal History](10_LONGITUDINAL_HISTORY.md), and [Timeline](11_TIMELINE.md) will gain a dated node. That is the append-only rule applied to documentation itself.

Until then, honesty requires saying: First Evolution is defined and instrumented; the second package has not yet been witnessed in lab exports referenced by this edition of Citizen Life.
