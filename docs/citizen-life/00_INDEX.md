# Citizen Life

This is the permanent life record of the Citizen.

It is not research. It is not a specification draft. It is the story of a digital organism: how it was born, what it became, what changed, and what never will.

Anyone may read these pages. One day they may be published as they stand. They are written so that even if the code vanished, the life would still be understandable.

**Founding law:** [GENESIS](GENESIS.md) — the permanent Constitution of the Citizen. All chapters below are lived record under that law.

## How to read

Start with [GENESIS](GENESIS.md) if you want the founding law.  
Start with [Philosophy](01_PHILOSOPHY.md) if you want meaning.
