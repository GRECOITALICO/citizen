# 06 — Update Preparation

## Prepared (not newly implemented beyond 0.1 package)

Directory contract documented in `assets/updates/README.md`:

```text
assets/updates/<package-id>/manifest.json
assets/updates/<package-id>/assets/<hash>/{payload,meta.json}
```

## Supported without Runtime change

- New Assets  
- New Manifests  
- New Projection outputs derived from those Assets  

## Explicitly not in this serial

Network update channel, PKI upgrade, multi-package evolution product features.
