# 02 — Birth

## Flow

```
./install.sh
  → install (Birth)
  → boot
  → serve UI
```

## Birth creates

| Artifact | Location (under CITIZEN_HOME) |
|----------|-------------------------------|
| Identity | `identity/` |
| Manifest | `manifest/current.json` |
| Evidence | `evidence/` |
| Telemetry | `telemetry/telemetry.jsonl` |
| Diary | `diary/life.jsonl` |
| Assets | `assets/` (content-addressed) |
| Projection | `projection/` |
| UI narrative | `ui/terminal.jsonl` |

## Once only

`boot/BOOTSTRAP_DISARMED` — Birth refused thereafter. Evolution uses Sync.
