# 04 — Update

## Law

Runtime is not replaced wholesale. Update installs **signed Assets** + new signed Manifest.

Preserved across Sync:

- Identity  
- Evidence  
- Diary  
- Continuity of Manifest history (`manifest/history/`)

## One button

UI Sync / CLI `citizen-seed update`:

`check → download → verify → apply`

States (visible): Current → Update Available → … → Updated.

Packages: `assets/updates/*/`.
